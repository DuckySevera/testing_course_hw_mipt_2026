# Чек-лист: выбор ингредиентов пиццы

## Требование

Пользователь может добавлять и удалять ингредиенты у базовой пиццы.

| Ингредиент | Цена за порцию, руб. |
|------------|----------------------|
| Пепперони | 60 |
| Ветчина | 70 |
| Грибы | 50 |
| Лук | 30 |
| Оливки | 40 |
| Бекон | 80 |

**Лимиты:**
- каждого ингредиента можно добавить только 1 порцию;
- минимум 1 ингредиент;
- максимум 5 ингредиентов.

**Поведение интерфейса:**
- при отсутствии ингредиентов выводится нотификация «Необходимо добавить хотя бы один ингредиент»;
- при отсутствии ингредиентов блокируется кнопка удаления ингредиента;
- при добавлении ингредиента блокируется кнопка добавления этого же ингредиента;
- при добавлении 5 ингредиентов блокируются кнопки добавления ингредиентов.

## Что я считаю по умолчанию

В требовании не всё описано, поэтому для чек-листа я исхожу из таких предположений (их нужно уточнить, см. раздел «Вопросы»):

- изначально у базовой пиццы 0 ингредиентов;
- цена пиццы = цена базовой пиццы + сумма цен выбранных ингредиентов;
- у каждого ингредиента есть свои кнопки «Добавить» и «Удалить».
